# Attributed source data

`DispersionAllPressures.txt` is the unmodified ancillary file supplied with
Godfrin et al., *Physical Review B* **103**, 104516 (2021),
[arXiv:2012.09067v1](https://arxiv.org/abs/2012.09067v1).
The original submission and its data are attributed to the authors under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
See `source.json` for the source URL, hash, units and measurement scope.

The table contains 1,050 wavevector rows and seven energy/error column pairs.
There are 7,118 valid pairs and 232 missing pairs. The original UTF-16 bytes and
`NAN` markers are retained. Missing observations are not zero-energy states.

All seven pressures refer to low-temperature superfluid conditions. These data
do not establish a temperature-driven phase transition or E8 symmetry in helium.
